# Xona Space Systems и CantiSpace: документация и патенты

Дата сбора: 2026-10-12. Источник — веб-поиск. Страницы патентов напрямую не открывались (доступ к хостам закрыт сетевой политикой), номера нужно проверить на первоисточнике.

## Xona Space Systems (LEO PNT, группировка Pulsar)

### Техническая документация

Официального публичного ICD (Interface Control Document) для сигналов Pulsar не найдено. По [вакансии технического писателя](https://www.builtinsf.com/job/technical-writer-spacecraft-manufacturing/10125131) ICD ведутся внутри компании.

Открытые материалы:

- [Insights into Xona Pulsar LEO PNT: Constellation, Signals, and Receiver Design](https://arxiv.org/pdf/2509.19551) — сигналы X1 (L1) и X5 (L5), DSSS, EFQPSK, CSK.
- [Xona Pulsar Compatibility with GNSS](https://arxiv.org/pdf/2509.16183) — X1: полоса 1,8 МГц, 1,023 Мчип/с; X5: 17,7 МГц, 10,23 Мчип/с. Данные из регуляторных заявок, могут отличаться от ICD.
- [Xona Pulsar Single-Satellite Positioning: System Perspective and Experimental Validation](https://arxiv.org/pdf/2602.06376)
- [World's First Authenticated Satellite Pseudorange from Orbit](https://arxiv.org/pdf/2509.21601)
- [Презентация Xona на ICG LEO-PNT Workshop 2023](https://www.unoosa.org/documents/pdf/icg/2023/ICG_WG-S_LEO-PNT_Workshop_June_2023/ICG_LEO-PNT_Workshop_2023_04.pdf)
- [eoPortal: Xona](https://www.eoportal.org/satellite-missions/xona)
- [Spirent SimXona (симулятор сигналов Pulsar)](https://www.gpsworld.com/spirent-to-generate-xona-pulsar-production-signals-via-simxona)
- [Демонстрационные PNT-сигналы](https://xonaspace.com/xonademospntsignals)
